# AI Context Map

This directory is the minimum-token context layer for eRespawn Premium.

Read in this order for non-trivial work:
1. root `AGENTS.md`
2. `CURRENT_STATE.md`
3. nearest scoped `AGENTS.md`
4. targeted source/tests
5. only the task-relevant workflow/decision/upstream references

Do not load every file here by default. `REPO_MAP.md` is navigation, `DECISIONS.md` is durable architecture, and `CURRENT_STATE.md` is the current handoff state.
