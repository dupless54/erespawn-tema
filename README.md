# eRespawn Premium Discourse Theme

A modern, premium-quality full theme for current Discourse releases.

## Foundation goals
- Native Discourse behavior first; no fragile template takeover.
- Premium topic lists and consistent content surfaces.
- Mobile-first desktop/tablet/mobile/small-screen design.
- Automatic light/dark compatibility through core CSS variables.
- Accessibility-conscious focus and reduced-motion behavior.
- Compatibility with avatar decorations, nameplates, flairs, badges and optional cosmetic plugins.
- Official Discourse Theme CI and core-feature system tests.

## Install
In Discourse Admin, install a theme from Git and use:

`https://github.com/dupless54/erespawn-tema.git`

## Development
Canonical AI/developer guidance lives in `AGENTS.md`. The `docs/ai/` and `.agents/skills/` files implement the minimum-token workflow used by this project.

The first development phase establishes the design system, premium native topic-list styling, responsive behavior, and upgrade-safe CI baseline. Additional page-specific premium passes will build on this foundation.
