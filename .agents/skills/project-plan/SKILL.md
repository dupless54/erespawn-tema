# Project Plan

Plan only after the task packet.

1. Restate the locked goal and exact allowed paths.
2. Identify the smallest current source/tests required.
3. If version-sensitive, name the exact official Discourse guide/core reference to verify.
4. Split implementation into reversible increments.
5. Define targeted checks and required CI before editing.
6. Call out cosmetic/avatar, accessibility, responsive, dark-mode, and upgrade-safety risks when applicable.

Do not turn a focused task into a redesign or architecture migration unless the evidence requires it.
