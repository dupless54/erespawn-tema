# Project Update State

Update `docs/ai/CURRENT_STATE.md` only for facts that materially change how the next agent should work.

Record:
- merged or active phase;
- current architectural/design-system choices;
- compatibility invariants discovered in real source/tests;
- known blockers or deferred work;
- next validation gate.

Do not turn CURRENT_STATE into a changelog. Put durable architectural decisions in `docs/ai/DECISIONS.md` and historical release notes elsewhere.
